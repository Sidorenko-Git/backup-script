1. СКРИПТ: setup_drives.sh
--------------------------------------------------------------------------------
НАЗНАЧЕНИЕ:
Автоматически запрашивает список всех доступных Google Shared Drives через API, 
формирует уникальные имена remotes и записывает индивидуальные конфигурационные
секции для каждого диска в rclone.conf.

БЛОК-СХЕМА ЛОГИКИ:

       [ Старт: setup_drives.sh ]
                   │
                   ▼
       [ Проверка наличия 'jq' ]
                   │
                   ▼
 [ Вызов 'rclone backend drives gdrive_ws:' ] ──► (Запрос списка 46 дисков через API)
                   │
                   ▼
  ┌──► [ Чтение очередного ID и Name диска ]
  │                │
  │                ▼
  │    [ Очистка имени от спецсимволов ]
  │  (буквы, цифры, подчёркивание, дефис)
  │                │
  │                ▼
  │    [ Формирование remote_name ]
  │         (например: drive_Backups_00)
  │                │
  │                ▼
  │  [ Выполнение 'rclone config create' ] ──► (Запись [drive_...] в rclone.conf)
  │                │
  │                ▼
  └─────── (Есть ещё диски в списке?)
                   │ (Нет)
                   ▼
         [ Завершение работы ]

2. СКРИПТ: mount_all.sh
--------------------------------------------------------------------------------
НАЗНАЧЕНИЕ:
Находит в rclone.conf все созданные секции 'drive_*', подготавливает локальные 
точки монтирования в /mnt/gdrive_shared/<Имя_Диска> и заменяет/монтирует их 
в фоновом режиме через FUSE (rclone mount --daemon).

БЛОК-СХЕМА ЛОГИКИ:

       [ Старт: mount_all.sh ]
                   │
                   ▼
    [ Проверка/Создание /mnt/gdrive_shared ]
                   │
                   ▼
 [ Запрос списка remotes (rclone listremotes) ] ──► (Фильтр по префиксу 'drive_')
                   │
                   ▼
  ┌──► [ Выбор очередного remote (drive_X) ]
  │                │
  │                ▼
  │    [ Формирование пути монтирования ]
  │         (/mnt/gdrive_shared/X)
  │                │
  │                ▼
  │    [ Создание целевой директории ]
  │                │
  │                ▼
  │  [ fusermount -uz (Сброс старых зависших FUSE) ]
  │                │
  │                ▼
  │  [ Запуск 'rclone mount drive_X: ... --daemon' ] ──► (Монтирование в фоновый режим)
  │                │
  │                ▼
  └─────── (Остались несмонтированные remotes?)
                   │ (Нет)
                   ▼
 [ Финал: Все 46 дисков смонтированы ]


# Создадим папку для кэша на большом диске
mkdir -p /mnt/encrypted_backup/rclone_cache

# Внутри цикла скрипта mount_all.sh вызовите rclone так:
rclone mount "$remote" "$target_dir" \
    --config="$CONFIG_PATH" \
    --vfs-cache-mode full \
    --vfs-cache-max-size 50G \
    --cache-dir /mnt/encrypted_backup/rclone_cache \
    --allow-other \
    --daemon
